## Before Installation

- Download the version marked **Latest** whenever possible. The current release is a beta.
- Verify that the installer matches your operating system and processor architecture.
- Back up important data before upgrading.
- The Windows installer is currently unsigned. If your browser or operating system displays a security warning, verify the file name and version before continuing.
- When reporting an issue, include the GeoCRM version, operating system version, and a screenshot of the error.
