# GeoCRM

Official download repository for GeoCRM releases.

> This repository is used to distribute installable application packages. Source code is not included.

## Download the Latest Version

Visit the [Releases](https://github.com/fuyediao/GeoCRM/releases) page, select the latest version, and download the appropriate installer from **Assets**.

| Platform | Common package formats |
| --- | --- |
| Windows | `.exe` / `.msix` |
| macOS (Apple Silicon) | `.dmg` / `.pkg` |
| macOS (Intel) | `.dmg` / `.pkg` |
| Linux | `.AppImage` / `.deb` |
| Android | `.apk` |

> Available platforms and package formats may vary by release. Refer to the release notes for details.

## Before Installation

- Download the stable version marked **Latest** whenever possible.
- Verify that the installer matches your operating system and processor architecture.
- Back up important data before upgrading.
- If your browser or operating system displays a security warning, verify the file name, version, and publisher before continuing.
- When reporting an issue, include the GeoCRM version, operating system version, and a screenshot of the error.
