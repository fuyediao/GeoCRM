# GeoCRM

GeoCRM 各平台正式版本的下載倉庫。

> 此倉庫主要用於存放可安裝的版本套件，不包含 GeoCRM 的完整開發原始碼。

## 下載最新版

請前往 [Releases](https://github.com/fuyediao/GeoCRM/releases) 頁面，選擇最新版本，並在 **Assets** 中下載適合您裝置的安裝包。

| 平台 | 常見安裝包格式 |
| --- | --- |
| Windows | `.exe` / `.msix` |
| macOS（Apple Silicon） | `.dmg` / `.pkg` |
| macOS（Intel） | `.dmg` / `.pkg` |
| Linux | `.AppImage` / `.deb` |
| Android | `.apk` |

> 實際提供的平台與檔案格式，請以各版本的 Release 說明為準。

## 安裝前注意事項

- 建議優先下載標示為 **Latest** 的穩定版本。
- 請確認作業系統與處理器架構符合安裝包要求。
- 升級前建議備份重要資料。
- 若瀏覽器或作業系統顯示安全提示，請先核對檔名、版本及發布者。
- 遇到問題時，請在回報中附上 GeoCRM 版本、作業系統版本及錯誤畫面。
